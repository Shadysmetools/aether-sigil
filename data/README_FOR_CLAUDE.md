# AETHER SIGIL: CHRONICLES OF THE CAPSULE REALMS

**Tagline:** Collect. Command. Evolve. Conquer.

## What this package is
An original 3D anime tactical monster-board game bible. It uses the broad concept of capsule-deployed monsters, tactical terrain, Symbols, towers, evolution and grid combat, but all creative identifiers are original.

## Files
- `AETHER_SIGIL_MASTER_GAME_BIBLE.json` — master machine-readable specification.
- `1000_MONSTERS.csv` — 1,000 original monster records with stats, roles and abilities.
- `120_STAGES_AND_OPPONENTS.csv` — 12 towers × 10 stages, opponents, rules and enemy rosters.
- `DIALOGUE_LINES.csv` — stage-specific intro/midbattle/defeat/boss dialogue.
- `AETHER_SIGIL_GAME_BIBLE.pdf` — readable design document.

## Important design target
Each stage should be rendered as a **3D isometric tactical arena**, not as a flat continent map. Use distinct terrain, elevation, chokepoints, capsule nodes, Symbols, hazards, bridges, portals and tactical objectives. Every tower should have a recognizable visual identity and a different opponent strategy.

## Scaling target
The monster database is intentionally structured so it can be imported into a game prototype, spreadsheet, database or AI content pipeline. The 1,000 entries are original generated seeds; before commercial release, art, final lore, balance, names and trademarks should receive human review.
