# Aether Sigil - generated placeholder art MANIFEST

Generated by `tools/aether_art.py` (art) and `tools/make_manifest.py` (this file). Original work; every colour is a
blend of the 7 brand tokens (same maths as `game/scripts/theme_colors.gd`). Re-run both scripts to rebuild.

- **365 PNG** (5.7 MB) under `png/`, **365 SVG** sources (1.0 MB) under `svg/`, 21 review previews under `previews/`.
- Every PNG has an SVG twin at the same relative path (`png/x/y.png` <-> `svg/x/y.svg`). SVG and PNG are drawn
  from one primitive list, so they match. PNGs are transparent, 4x supersampled, LANCZOS-downscaled.

## Godot 4.7 import guide

1. `res://` is the `game/` folder (that is where `project.godot` lives). Copy **`art/generated/png/`** to
   **`game/art/generated/png/`**, so a file is `res://art/generated/png/tiles/T01_verdant_spire/ground.png`.
   Don't copy `svg/`, `tools/` or `previews/`. If you copy the whole folder anyway, each one has a `.gdignore`
   so Godot skips it.
2. Import settings (Import dock, then *Save as Default* for Texture2D):
   - Compress: *Lossless* for UI, or *VRAM Compressed* for tiles and tokens on mobile.
   - Mipmaps: **on** for tiles, props and tokens (they are drawn at 0.33-0.5x). Off for UI.
   - Project Settings > Rendering > Textures > Canvas Textures > Default Texture Filter: **Linear Mipmap**.
     This is not pixel art, so never use Nearest.
   - Fix Alpha Border: on. Premult Alpha: off.
3. You can import the SVGs directly too (Godot rasterises them with ThorVG; set `svg/scale` = 2.0 to match the
   PNGs). The PNGs are the tested path.

### Isometric tiles: `png/tiles/<Txx_tower>/<type>.png` - 256x320 px (SVG 128x160 at 2x)

- Top face = 2:1 diamond, **128x64 SVG units** (256x128 px in the PNG).
- **Anchor = centre of the ground-plane diamond = SVG (64,124) = PNG pixel (128,248).** It is the same point on
  every tile, raised or not. Raised tiles lift the top face by `raise x 64` units: stone 0.35, elevation 0.6,
  obstacle 0.8, everything else a 6-unit slab. These are the same `raise` values as `game/data/game_rules.json`.
- Sprite2D recipe for the current board (`board_view.gd`: TILE_W 84, TILE_H 42):
  ```gdscript
  var s := Sprite2D.new()
  s.texture = load("res://art/generated/png/tiles/%s/%s.png" % [tower_folder, type])
  s.centered = false
  s.offset = Vector2(-128, -248)        # texture pixels: anchor -> origin
  s.scale = Vector2.ONE * (84.0 / 256.0)  # = 0.328125; PNG top face is 256 px wide
  s.position = tile_center(c)           # ground-plane centre, NOT top_center()
  ```
  For TILE_W = 128 use scale 0.5. TileMapLayer/TileSet alternative: tile_shape Isometric, tile_size (256,128),
  one 256x320 region per tile, `texture_origin = Vector2i(0, 88)` (ground centre 248 minus region centre 160;
  Godot draws the region centred on the cell, shifted by -texture_origin). UNVERIFIED in-engine: if tiles sit
  88 px off, flip the sign. The Sprite2D recipe above is the one the stage previews were built with.
- Draw order: back-to-front by screen Y of the ground centre (`y_sort_enabled`, or sort by x+y as `board_view.gd`
  already does). Top faces are grown ~0.4 SVG units, so adjacent tiles overlap slightly and show no seams.
- Ground has three variants (`ground`, `ground_v2`, `ground_v3`). Pick one with `(x*7 + y*13) % 3`.
- Bridges: use `bridge` when the neighbouring bridge or walkable tile is along the board X axis, `bridge_y` when
  it is along the Y axis.
- Tiles that host a standing object (player/enemy_symbol, capsule_node, relic, warp_gate) are floor engravings
  only. Stack the matching prop on top as a separate sprite, so you can animate it.

### Props: `png/props/*.png` - 256x384 px (SVG 128x192 at 2x)

- **Foot anchor = SVG (64,176) = PNG pixel (128,352).** Put it on the tile's TOP-face centre (`top_center(c)`).
- Sprite2D: `centered=false, offset=(-128,-352)`. Use scale **0.25-0.33** on the 84 px board (the preview uses
  0.275 = 0.55 x 0.5). Give it the same y-sort key as its tile + 0.5 so units can stand in front.
- The capsule node is a faceted hex-crystal vessel in a gold gyroscope cage with two rings tilted +-55 degrees.
  It deliberately has **no** equator band, no front button and no two-tone sphere.

### Element icons: `png/icons/elements/*.png` - 256x256 (SVG 64x64 at 4x)

One per `element_family` in the bible (Fire, Water, Wind, Earth, Wood, Ice, Thunder, Light, Dark, Tech, Space,
Arcane). The ring colour is `theme_colors.gd family()`. Use them in a TextureRect with expand mode
*Keep Aspect Centered*; they read cleanly down to 24 px.

### Unit tokens: `png/tokens/` - 256x256 (SVG 128x128 at 2x)

- `frames/<ally|enemy>_<family>.png`: the outer ring is the team colour (ally = Aether Cyan, enemy = Ember), the
  inner ring is the element, and the element badge sits at the bottom. **Creature slot: a circle of radius 82 px
  centred at PNG (128,120).**
- `silhouettes/*.png` (256x256): stag, hopper, phoenix, colossus, beetle, drake. These are Soft Silver stand-ins.
  Place each as a child Sprite2D centred on the slot, scaled to 0.72 of the slot box (see `samples/`), and use
  `modulate` to tint.
- Token foot: put the badge bottom (PNG (128,~250)) on `top_center(c)`. Use scale ~0.25 on the 84 px board.

### UI: `png/ui/`

- `buttons/btn_<move|attack|skill|defend|wait>_<normal|pressed|disabled>.png`: 192x192. Use a TextureButton
  (normal / pressed / disabled textures). The art has no text: put a Label under the button so it can be localised.
- `turn_order/slot_<ally|enemy>[_active].png`: 144x144. Put the index number as a Label over the top-left corner
  triangle (about 0-40 px) and the portrait inside at inset 16 px.
- `objective/checkbox_<unchecked|checked|failed>.png`: 128x128. Use CheckBox theme icons at 24-32 px.
- `panel/panel_border.png`: 384x384, for a **NinePatchRect / StyleBoxTexture with all patch margins = 56 px**.
  The corner ornaments sit inside the 56 px corners. `panel_header.png` (384x64) is a title plaque; use
  NinePatch margins left/right 40, top/bottom 0.

### Data notes for the dev

- The tile set covers all **21 tile types used in any `map_grid`** of the 120 stages. `stone` appears in grids
  but in no `map_legend`.
- `sky`, `ruins`, `space` and `rift` are legend-only: they never appear on a map, so no art was made for them.
  The generator can add them.
- Tower folders: `T01_verdant_spire`, `T02_ember_bastion`, `T03_tideglass_citadel`, `T04_frost_meridian`, `T05_iron_labyrinth`, `T06_storm_crown`, `T07_obsidian_eclipse`, `T08_sunken_archive`, `T09_astral_observatory`, `T10_crystal_sanctum`, `T11_rift_frontier`, `T12_sunforge_throne`.
