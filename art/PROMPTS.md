# Aether Sigil: image-generation prompt pack

> **Ownership note: read first.** These prompts are for exploration and placeholders only. A human artist should redraw every final in-game and marketing image from scratch, using the AI output as rough reference at most. That way the studio owns clean, registrable copyright, and no generated artefact ships. Don't trace the AI output or the concept sheets in `art/concepts/`.

## How to use

Each prompt describes **only the look**. Paste the **shared style block** first, then the subject prompt, then the **negative block**.

**Shared style block**
> anime, bold clean linework, cel shading, glowing magical accents, crisp two-tone shadows, high-fantasy mystic-tech, palette of midnight navy #0B1220, aether cyan #22D3EE, verdant green #2ECC71, ember red-orange #FF6B3D, crystal violet #B15CFF, sigil gold #F6C445, soft silver #D6DEE9, polished game key-art finish, sharp focus

The **bold names** below are labels for the team. Don't paste them into the generator; paste only the description.

**Negative block**
> no text, no logo, no watermark, no signature, no extra fingers, no blurry linework, no photorealism, no two-tone ball with a centre band and button, no existing franchise characters or creatures

**House motifs.** Use these wherever a prompt says "sigil gear":

| Motif | Look |
| --- | --- |
| Sigil | compass star |
| Prism Core | faceted elongated crystal |
| Portal | violet ring |
| Relic | gold triangle |
| Capsule | faceted hex-crystal vessel, or a gold gyroscope cage of tilted rings around a crystal core. **Never** a banded sphere. |

**Aspect ratios**

| Use | Ratio |
| --- | --- |
| Characters | 2:3 portrait |
| Monsters | 1:1 or 4:5 |
| Arenas | 16:9 isometric |
