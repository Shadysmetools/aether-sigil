# Audio hooks - game event -> sound id

Generated by `game/audio/tools/make_sfx.py` (edit the `event` text there, not here). Call `AudioManager.play_sfx("<id>", position_or_null, pitch_jitter)`; ids with variants pick one at random. Music: `AudioManager.play_music("<id>", crossfade_sec)`. Ambience: `AudioManager.play_ambience_for_theme(tower.theme)` or `play_ambience("<id>")`. Voice: `AudioManager.play_voice("<line_id>")` (silent no-op when the file is missing).

Suggested pitch_jitter: 0.06 for steps / hits / chips, 0.03 for casts, 0 for UI, stings and music-like cues.

Statue attack sequence: `stone_crack_build` (0.6 s) -> `petrify_shatter` + `monster_awaken_roar_*` (or a `monster_roar_<kind>` by species) -> `cast_<element>` / `hit_*` -> `repetrify`. Hits on a statue: `stone_chip_hit`; KO: `statue_crumble`.

Sync points for the animation pass: `stone_crack_build` crackle peaks and cuts at ~0.62 s (start `petrify_shatter` there; its impact is at 0 s); `repetrify` settle thunk lands at ~0.57 s; `statue_hop` landing clunk at ~0.16 s; `evolve_build` is 2.5 s to its peak, then `evolve_burst`; `fusion_merge` flash at ~1.85 s.

## Voice

| Event | Call |
|---|---|
| Dialogue box shows a line ({speaker, line} from story.gd: scenes, barks, stage intros) | AudioManager.play_voice_line(speaker, line) - looks up md5(speaker + newline + line) in voices/voice_index.json |
| Dialogue advanced / skipped | AudioManager.stop_voice() |
| Tower reward scene (rare_drop) | AudioManager.play_voice("rare_drop_<tower_id>") |

Music ducks by 9 dB while a voice plays. Lines that are not rendered yet are silent (returns false).
